## Capability and debt disposition

Lab/results, I4 longitudinal continuity, notifications and EACCE remain future; Pharmacy/Admin frontend integration and hosted I3 parity are gaps, not five completed Live portals. Device/assistive-technology, native Egyptian editorial/participant and distribution/rights validation remain outstanding. Existing health disposition **B — healthy with non-blocking debt** is inherited from accepted evidence, not a fresh whole-project runtime audit. This docs sprint preserves the implementation; it does not remediate that debt. A whole-project health review is required before the next major milestone.

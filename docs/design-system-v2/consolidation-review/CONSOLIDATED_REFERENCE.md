## Cohesion judgment and priorities

Actual pinned PNGs show coherent white/violet-tinted Light and ink/lavender Dark planes, source-exact logo, typography and text-led state cues. Patient is date-led; Doctor source/editor-led; Pharmacy route-led; Lab stage/blank-result-led; Admin list/membership-led. A universal dashboard would lose this distinction. [Exact inspected images/hashes and existing QA](REVIEW_AND_HANDOFF.md#pinned-browser-evidence-and-reuse) substantiate this judgment; no new screenshots or browser test passes are claimed.

Priorities before later implementation approval: (1) resolve alias/shape/focus/critical-text rules and state/audience contracts; (2) approve shell/adaptation and screen-specific source ordering using realistic authorized synthetic content; (3) complete applicable platform/AT/rights evidence. These are specification/release priorities, not newly diagnosed runtime P0/P1 defects. No material blocking visual/clinical contradiction was found that warrants another aesthetic round now.

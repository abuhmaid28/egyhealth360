PROPOSED ARCHITECTURE / V0.1

One grammar.
Room for real work.

A vendor-neutral DTCG-compatible proposal: foundational values → semantic intent → component decisions. Density changes without changing identity or authority.

01

Foundation

Local bilingual type, restrained navy/teal, neutral light planes, 4px sub-rhythm / 8px layout rhythm. Existing evidence supplies each proposal.

02

Semantic intent

Canvas, surface, text, action, focus, private audience, release audience, warning, error, success. Brand teal never means “clinically normal”.

03

Component decisions

Action, field, status, source row, context ribbon, audience boundary and confirmation. Proposed taxonomy only; no React API is frozen.

04

Usage modes

Patient: attentive spacing and one appointment anchor. Clinician: compact source divisions. Operations: aligned work rows with exact artifact scope.

05

Responsive behavior

1440+ constrained canvas; 768 tablet reflow; 390 and 320 single-column patient context. Below 720, clinician becomes visit review, not squeezed signing.

06

Motion & focus

140ms color feedback, no animated clinical success. Reduced-motion removes transitions. 3px dark focus ring with a 3px surface gap.

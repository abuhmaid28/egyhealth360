05 / Meaning before color

✓ Confirmed! Check required! Could not loadi Information⊘ Unavailable

Green success, amber caution, red error, blue information, neutral unavailable. Each keeps explicit text and a non-color cue.

Samples describe UI semantics, not new clinical rules or permissions. An empty patient view never proves that no source exists.

06 / Reusable across five purpose-built portals

Keep logo, colors, type, icon strokes, focus and source provenance consistent. Vary density and task arrangement for Doctor, Pharmacy, Laboratory and Admin after approval. Do not give each portal its own palette.

Source grammar

Source type → exact shared state → content purpose → author + date → explicit action. Summary and recommendation stay independent. A recommendation is not a booking.

State grammar

Loading: no stale facts. Error: unknown state + read-only recovery. Empty: bounded available information. Unavailable: uniform copy without source details, causes or counts.

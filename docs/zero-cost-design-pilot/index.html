Interval asks: what needs my attention?

Spatial contrast puts the confirmed event first. The professional workspace uses simultaneous, separately owned document surfaces. Risk: the date anchor may dominate on smaller displays.

Relay asks: which source am I acting on?

Chronological cues connect only the displayed, independently permitted sources. The professional workspace uses a continuous document column with purpose boundaries. Risk: more vertical travel on phones.

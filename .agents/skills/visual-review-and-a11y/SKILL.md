# Visual review and a11y

Compare approved design, baseline and candidate against the [quality gates](../creative-direction/references/workflow.md#quality-gates). Record actual results in the [evidence manifest](references/evidence-manifest.md). Exercise keyboard, contrast, reflow, bilingual direction, motion and state recovery. Separate objective outcomes from aesthetic scores. Bind defects, rechecks and verdict to the exact final tree. Record which checks were performed and which still need real devices, assistive technology or user testing.

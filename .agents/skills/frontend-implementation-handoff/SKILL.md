# Frontend implementation handoff

Use the [workflow](../creative-direction/references/workflow.md). Verify the approved specimen, explicit implementation authority, sole writer, base HEAD/tree and exact routes and paths. Provide state matrix, component mapping, bilingual copy, rights, negative authority checks, QA and rollback. Escalate changes to behavior, contracts or scope.

# Locally served brand fonts

Inter Latin variable and Noto Sans Arabic Arabic variable WOFF2, served from
the Fontsource distribution. Both are licensed under SIL OFL 1.1;
the original license notices are included here. No runtime font service or package
dependency is used. Inter provides Latin glyphs alongside Noto Sans Arabic.

Sources:
- https://cdn.jsdelivr.net/fontsource/fonts/inter:vf@latest/latin-wght-normal.woff2
- https://cdn.jsdelivr.net/fontsource/fonts/noto-sans-arabic:vf@latest/arabic-wght-normal.woff2
- https://github.com/google/fonts/tree/main/ofl/inter
- https://github.com/google/fonts/tree/main/ofl/notosansarabic
